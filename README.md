## Проекты "в работе"

**Живая книга проекта**
Интерактивная энциклопедия проекта: собирается из отдельных глав, растёт вместе с проектом, переиздаётся для партнёров и инвесторов. Первый экземпляр — книга проекта BSF.
Универсальный скилл позволяет собрать такую же книгу для любого другого проекта.
Репозиторий: [living-project-book](https://github.com/Sergius-nsk/living-project-book)

**ИИ-ферма для BSF**
Автоматизированная мушиная ферма для чёрной львинки: переработка пищевых отходов в белковую биомассу и удобрение. Технология, оборудование, экономика проекта.

**Проект_РЭО**
Переработка органических отходов. Проект на стадии изготовленного MVP: выход из «долины смерти», работа с агрохолдингами, подготовка к инвестированию.

**КБ-ИИ**
Конструкторское бюро, где ИИ-агенты помогают разрабатывать новую технику: 3D-модели, конструкторская документация, инженерные расчёты.

**ИИ-ферма для перепелов**
Автоматизированная птицефабрика для перепелов-несушек и бройлеров — по модели современных куриных птицефабрик, с автоматизацией климата, кормления и учёта.
